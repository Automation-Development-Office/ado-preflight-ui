Git TLS and Controller TLS follow their own settings. A new form verifies Git certificates. An imported file that omits Git Skip TLS still skips, and the form shows that checkbox checked. Unchecking it is saved and used for clone, fetch, pull, and push. The restart script stops only the named Preflight container, builds before replacing a running container, and publishes on all host interfaces unless BIND_ADDR is set. The workflow preview shows only job templates generation would create. Git tokens stay in mode 0600 ADO credential files.
